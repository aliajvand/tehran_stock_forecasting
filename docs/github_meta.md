# GitHub Metadata: Tehran Stock Forecasting Platform

## Repository Title
`tehran-stock-forecasting`

## One-Line Tagline
Quantitative forecasting and market microstructure platform for Tehran Stock Exchange (TSETMC) using Hybrid LSTM + GNN and walk-forward cross validation.

## About / Description
Production-grade quantitative finance platform indexing 10,874 historical price days and institutional (Haghighi/Hoghughi) order flow facts across 428 TSETMC instruments. Implements 5-fold expanding-window walk-forward cross validation, reaching 69.85% directional accuracy on trending holdouts, analytical SQL marts, a sub-second FastAPI microservice, and a responsive Plotly/Dash operations portal.
