# دامنه پروژه (Scope)

## هدف
پیش‌بینی روند روزانه سهام بورس تهران با ترکیب LSTM (سری زمانی) + GNN (گراف جریان
پول) + تحلیل احساسات اخبار کدال. **هدف کیفی: دقت جهت‌دهی بالای ۷۰٪.**

## داخل دامنه

| مورد | مقدار |
|---|---|
| افق پیش‌بینی | روزانه، ۱ تا ۳ روز آینده (`prediction.horizon_days`) |
| خروجی مدل | کلاس `up` / `down` / `neutral` + احتمال + بازدهی تخمینی |
| آستانه کلاس | ±۱٪ (`prediction.threshold_pct`) |
| نمادها | ۱۸ نماد از ۸ صنعت (`configs/symbols.yaml`) |
| بازه تاریخی | ۳ سال اخیر (`data.history_years`) |
| بازار | فقط بورس (بازار اول و دوم) |
| منابع داده | TSETMC از طریق `algotik-tse` + اطلاعیه‌های کدال |
| دیتابیس | SQLite تک‌فایلی (`data/bourse.db`) |

## خارج از دامنه (فاز فعلی)
- معامله خودکار (ارسال سفارش به کارگزاری)
- بازار پایه و فرابورس
- اختیار معامله و ابزارهای مشتقه
- کریپتو و بازارهای خارجی
- پیش‌بینی درون‌روزی (intraday) — داده intraday فقط ذخیره می‌شود

## نمادها به تفکیک صنعت

| صنعت | نمادها |
|---|---|
| فلزات (metals) | فولاد، فخوز، ذوب |
| پتروشیمی و پالایشی (petrochemical) | شپنا، شتران، تاپیکو |
| بانکداری (banking) | وبملت، وتجارت، وبصادر |
| خودرویی (automotive) | خودرو، خساپا |
| دارویی (pharma) | دارو، تیپیکو |
| مخابرات (telecom) | همراه، اخابر |
| سرمایه‌گذاری (investment) | وپارس، سرمایه |
| غذایی (food) | غبشهر |

## معیارهای موفقیت
1. **Directional Accuracy > 70٪** روی نمونه‌های غیر-neutral در اعتبارسنجی Walk-Forward
2. F1 (macro) بالاتر از خط پایه «همیشه neutral»
3. Sharpe مثبت در بک‌تست با کارمزد ۰.۳۷٪ و اسلیپیج ۰.۱٪
4. حداکثر افت سرمایه (MaxDD) کمتر از ۲۵٪

## ریسک‌ها و محدودیت‌ها
- **توقف نماد و صف‌های یک‌طرفه**: روزهای بدون معامله حذف می‌شوند و شکاف قیمتی
  ایجاد می‌کنند.
- **رژیم‌های بازار**: بورس تهران دوره‌های تورمی/رکودی شدید دارد؛ اعتبارسنجی
  Walk-Forward برای همین انتخاب شده و آموزش تک‌مرحله‌ای گمراه‌کننده است.
- **کیفیت داده کدال**: ساختار HTML کدال ممکن است تغییر کند؛ اسکرپر با fallback
  (codalpy) و مدیریت خطا نوشته شده.
- **نبود دیتای تیک تاریخی**: گراف جریان پول از هم‌حرکتی داده حقیقی/حقوقی ساخته
  می‌شود، نه از انتقال واقعی پول بین دو سهم.
